# LemCAD

**Professional CAD, redesigned for people who build things.**

This is the **public binary distribution repository** for LemCAD, developed by BuiltByLegacy.

> **Status: Pre-release — no validated public Windows installer is available yet.**

## Download
Visit **https://lemerydesigns.com/lemcad** for the Windows download page. Once a validated installer is published, the website will direct you to the latest approved stable release here.

## Releases and updates
- The **Releases** section will contain approved versioned Windows `.exe` installers, release notes, and checksums.
- Stable releases are intended for general users. Pre-release builds may be labeled alpha or beta.
- A future in-app updater will offer release notes and a user-approved update/relaunch process; that feature is **not yet available**.
- Never run an installer from an untrusted third-party download site.

## Privacy and support
Local CAD files remain yours. Never upload confidential customer geometry or proprietary engineering data to public GitHub issues. Feedback/reporting features are under development.

## Repository scope
This public repository is only for distributable binaries and user-facing release documentation. It does **not** contain the private CAD source code, build credentials, internal issues, or customer diagnostic reports.

The underlying application remains in early development, and has not been qualified for safety-critical or production-release engineering use.
